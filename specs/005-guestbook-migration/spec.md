## Goal

Add a Phinx database migration that creates the `guestbook_2` table.

## Requirements

- Create the migration with `docker compose run --rm php vendor/bin/phinx create CreateGuestbook2Table`, not by hand. It lands in `app/db/migrations/` as `<timestamp>_create_guestbook2_table.php`.
- The migration makes one logical change: it creates the `guestbook_2` table, using Phinx's `change()` method so it can be rolled back.
- Columns, all NOT NULL:
  - `id`: int, primary key, auto-increment
  - `posted_at`: datetime, default `CURRENT_TIMESTAMP`, with a normal (non-unique) index
  - `name`: varchar(32)
  - `email`: varchar(63)
  - `message`: varchar(256)
- Use the existing `app/phinx.php` config (mysql adapter, `utf8mb4`). Do not change it.

## Acceptance Criteria

- Exactly one new migration file exists in `app/db/migrations/`, with class `CreateGuestbook2Table`, generated by `phinx create`.
- The migration defines the `guestbook_2` table with the columns, types, lengths, NOT NULL constraints, `posted_at` default and non-unique `posted_at` index listed above.
- Rolling back the migration drops `guestbook_2`, because `change()` can be reversed.

## Out of Scope

- Running the migration
- Changing any code besides the migration file. For example, `GuestbookController` keeps reading from `posts`.
