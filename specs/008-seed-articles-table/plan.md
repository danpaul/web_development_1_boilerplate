## Seeder

Generate with:

```sh
docker compose run --rm php vendor/bin/phinx seed:create ArticlesSeeder
```

Keep the generated class (`ArticlesSeeder extends Phinx\Seed\AbstractSeed`, `declare(strict_types=1)`, docblock). Fill only `run()`:

```php
public function run(): void
{
    $data = [
        [
            'title' => 'Getting started with Docker Compose',
            'content' => 'Docker Compose lets you define all services of an app in one YAML file. ...',
            'author' => 'Alice Jansen',
            'created_at' => '2026-10-01 09:00:00',
        ],
        // ... 20 rows total
    ];

    $articles = $this->table('articles');
    $articles->truncate();
    $articles->insert($data)->saveData();
}
```

- No `getDependencies()`, no `id` key (auto increment).
- `truncate()` runs before insert, so re-running leaves exactly 20 rows (MariaDB `TRUNCATE` also resets auto increment to 1).

### Data rules

- Exactly 20 rows, literal arrays (no loops, no `date()`/`DateTime` computation).
- Topics: web development (PHP, MySQL/MariaDB, Docker, nginx, HTTP, routing, MVC, Composer, PDO, migrations, Git, HTML/CSS, security basics, etc.). One distinct topic per article; titles unique.
- `content`: 2–3 full sentences, plain text, no HTML.
- Authors (3, fictional, uneven split):
  - `Alice Jansen`: 8 articles
  - `Bram de Vries`: 7 articles
  - `Chloe Peters`: 5 articles
  - Interleave authors across dates (not grouped in blocks).
- `created_at`: fixed literal strings `'YYYY-MM-DD HH:MM:SS'`, one per day from `2026-10-01 09:00:00` to `2026-10-20 09:00:00`, rows in ascending date order (row 1 = oldest).
